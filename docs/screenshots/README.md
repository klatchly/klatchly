# Screenshots

Klatchly running against fake backends with made-up people and conversations, built with the packages of this repository (`beeper`, `accounts`, `llm`, `writing`, `agents`, `transcribe`). Desktop captures are 1440×900, phone captures an iPhone 15. The model-provider answers and transcripts are canned by the fakes.

Back to the [README](../../README.md).
